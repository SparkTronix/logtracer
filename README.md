# LogTracer

LogTracer — настольное WPF-приложение для просмотра системных журналов Windows в одном окне.

## Возможности

- Просмотр последних событий выбранных системных журналов в таблице.
- Список всех доступных журналов Windows с флажками; по умолчанию выбраны `Application`, `System` и `Security`.
- Поиск по журналу, источнику, сообщению и ID события.
- Фильтры по журналу, уровню, дате и времени.
- Просмотр полного текста выбранного события.
- Подсветка ошибок светло-красным фоном.
- Ручное, интервальное и событийное автообновление.
- Экспорт отфильтрованных событий в CSV.

Для доступа к журналу `Security` могут потребоваться права администратора.

## Запуск

Требуется .NET SDK 10 или новее:

```bash
dotnet run --project LogTracer/LogTracer.csproj
```
