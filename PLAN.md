# План реализации LogTracer

## 1. Проверяемый первый прототип

- Создать нативное Windows-приложение WPF на .NET.
- В одном окне показать последние события журналов `Application`, `System` и `Security`.
- Отобразить дату и время, журнал, уровень, ID события, источник и сообщение в таблице.
- Добавить поиск по журналу, источнику и тексту сообщения, а также отдельный поиск по ID события.
- Добавить фильтры по журналу и уровню события, ручное обновление и понятное состояние недоступного журнала.

**Критерий готовности:** приложение запускается, таблица заполняется доступными локальными журналами, фильтры и поиск обновляют результат без повторной загрузки.

## 2. Расширение просмотра

- Выбор доступных журналов Windows вместо фиксированного набора.
- Фильтрация по диапазону дат и времени.
- Панель подробностей выбранного события с полным текстом. **Выполнено.**
- Настройка числа загружаемых записей.

## 3. Обновление данных

- Автоматическое обновление по поступлению новых записей. **Выполнено.**
- Обновление с интервалом 5, 10, 15 или 30 секунд. **Выполнено.**
- Сохранение активного режима обновления между запусками.

## 4. Дополнительные возможности

- Сохранение активных фильтров между запусками.
- Экспорт отфильтрованных записей в CSV и JSON.

## 5. Подготовка к использованию

- Тесты для фильтрации и преобразования данных.
- Обработка прав доступа и ошибок чтения для каждого журнала.
- Сборка распространяемого Windows-пакета.

## Текущая остановка

Проверьте нижнюю панель деталей, режим «В реальном времени» и интервальные режимы обновления. После этого можно перейти к фильтрации по времени, списку доступных журналов или экспорту.
